# Executive Summary — COVID-19 Global Impact Dashboard

**Important data notice:** This project uses synthetic practice data generated for demonstration. It is not official COVID-19 information, does not represent real country observations, and should not be used for health or policy decisions.

The dataset contains 3,650 daily country records for 5 fictional country labels from 2021-01-01 to 2022-12-31. The interactive dashboard supports country and date filtering, daily case trends, a 7-day average, cumulative deaths, and end-of-period country comparisons.

## Data-based observations (within this synthetic dataset)
- Demeria: final cumulative cases 3,043,303; final cumulative deaths 26,266; peak single-day new cases 10,410 on 2022-02-18.
- Borealia: final cumulative cases 1,985,164; final cumulative deaths 17,949; peak single-day new cases 6,458 on 2022-11-05.
- Asteria: final cumulative cases 1,190,836; final cumulative deaths 10,680; peak single-day new cases 3,718 on 2022-11-14.
- Cyrenia: final cumulative cases 545,371; final cumulative deaths 4,535; peak single-day new cases 1,727 on 2022-02-20.
- Eldoria: final cumulative cases 1,367,151; final cumulative deaths 11,583; peak single-day new cases 4,581 on 2022-08-07.

Vaccination counts are included, but vaccination coverage is not reported because no population denominator is provided. The generated values are controlled by a fixed random seed; observed patterns are software-demo behavior, not evidence about the real pandemic.
